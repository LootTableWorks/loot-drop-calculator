# Campaign Launchpad

Campaign Launchpad turns one shared seed into a guided path through five public Loot Table Works tools: World Seed Studio, Character Foundry, One-Shot Forge, Campaign Arc Forge, and Player Chronicle. It recommends exactly three relevant standalone modules for the selected play spotlight without exposing bundles or private offers.

## Contract

- Four scopes: one night, full evening, mini arc, and campaign
- Three spotlights: exploration, intrigue, and survival
- Party sizes from three to six and tiers from one to five
- 240 validated setup combinations
- Five synchronized free-tool routes
- Three contextual `$3` standalone recommendations
- Shareable configuration URL, Markdown export, and validated Campaign Start JSON export
- No account, analytics, hosted AI runtime, persistent storage, or external runtime dependency

Campaign Start export generates the matching One-Shot Forge opening session from the selected scope and spotlight, then validates the combined document against the Campaign Workspace import contract before download.

Run `scripts/build.ps1` to validate and create the public archive.
