Before you choose

World Foundry module questions

Use the selector for a recommendation. Use these answers to confirm the catalog boundary before opening a product page.

Which World Foundry module should I buy first?

Start with the system blocking your current project. Choose Item Catalog for canonical objects and economy records, Merchant for shops, Crafting for recipes, Enemy Loot for rewards, Quest for connected contracts, or Encounter for phase-based threats.

Do I need to buy all six modules?

No. Every module is a standalone $3 product. Add another module only when you need its connected records. No bundle is currently offered.

What files and tools are included?

Each module includes structured JSON and CSV, documented schemas, and offline workflow tools. Engine starters and specialized utilities vary by module, so the product page is the final authority for exact current files.

Can I connect the modules to my own RPG data?

Yes. World Foundry uses stable IDs and documented references. Pair the matching modules for canonical records or map the external IDs to your own data.

Are these art, map, token, audio, or rules packs?

No. These are original system-neutral structured data and offline workflow products. They do not include battle maps, tokens, character art, audio, or rules-specific stat blocks.
