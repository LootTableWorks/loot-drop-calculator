# Gullwatch Beacon: Free Play Tonight Kit

Run a complete system-neutral fantasy one-shot tonight with about 10 minutes of preparation.

## What is included

- An illustrated eight-page adventure
- A one-page GM run sheet
- Gridless and numbered GM maps
- Six individual VTT tokens and a printable token sheet
- Three player handouts
- Three scaling profiles for a group of 3-6 players
- A local offline start page

The full session is designed for approximately 3-4 hours. No paid product is required to run or finish the adventure.
