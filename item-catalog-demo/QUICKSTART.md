# Five-Minute Quick Start

1. Open `START-HERE.html` for the package launchpad.
2. Open `item-explorer.html` to search, filter, randomize, inspect, and export items without installing anything.
3. Open `item-collection-builder.html`, enter a seed, and choose a biome, use case, tier ceiling, and item count.
4. Print the generated collection or export it as JSON.
5. Load `items.json` with the Unity, Godot 4, TypeScript, or JavaScript integration example.
6. Preserve `pitm-####` IDs when adding project-specific fields or balancing values.

Use `crafting_roles` and `compatible_disciplines` for recipe selection. Use `suggested_value` for economy calculations. The compatibility fields `effect`, `value`, and numeric `weight` remain available throughout the 2.x line.
