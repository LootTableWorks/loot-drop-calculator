# Illustrated Item Sample

This free sample includes 20 transparent 256px inventory icons mapped to the
20 Brineworn and Mossbound records already present in the 100-item catalog demo.

- `icons/`: one PNG per sampled stable item ID
- `atlases/demo-sample-atlas.png`: normalized 5x4 PNG sprite sheet
- `icon-map.json`: exact ID, filename, atlas cell, biome, and object-type mapping

The paid edition includes 100 mapped icons across the complete Brineworn coastal
and Mossbound forest item families. Artwork is AI-assisted, human-directed,
normalized, and QA-reviewed. Usage is governed by `USAGE-TERMS.md`.
