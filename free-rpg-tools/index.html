Before you open a tool

Straight answers

Do I need an account?
No. All eleven tools open directly in a modern browser.
Are the generators tied to one ruleset?
No. The narrative tools are system-neutral and avoid protected settings, characters, and rules text.
Is my imported data uploaded?
No. Data Doctor and Data Bridge process imported files in the active browser tab without a remote analysis service.
What makes a result reproducible?
Seeded tools record the seed and settings that produced the output. Numeric and file-audit tools return the same result from the same inputs.
